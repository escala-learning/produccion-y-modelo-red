# Producción y modelo RED · Scala Learning

Cómo se produce un recurso educativo digital (RED) de Scala con asistencia de IA, y cómo es un
RED terminado: la fábrica por estaciones, las fases con ejemplos, los agentes y sus prompts, la
verificación y la ronda de ajustes, la estructura de una unidad, los entregables y OVA Studio.

Un solo archivo, `index.html`, autocontenido. Se publica en GitHub Pages en cada cambio en `main`.

Las pautas de diseño, el marcado del Word y el catálogo de componentes están en el curso demo:
https://github.com/escala-learning/demo-unidad
